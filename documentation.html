Introduction

This is the developer documentation for CodeGhar. If you're integrating our APIs into your app or connecting to our services, start here.

How Our APIs Work

REST-style APIs, JSON responses, predictable URLs. Works the same whether you're calling from a mobile app, a website, or a backend script.

Heads Up

We update these docs when things change. If something looks wrong or you need a custom endpoint, contact us directly.

Authentication

All API requests need a Bearer token. You'll get your production key from us once your project is set up and deployed.

curl -X GET "https://api.codeghar.com/v1/user" \
     -H "Authorization: Bearer YOUR_TOKEN"
